> **统一约定（V1.0 §6.1）**
> - 业务接口统一前缀 **`/api/v1`**；本章所列路径为前缀之后的相对路径。
> - 请求与响应均 JSON；日期类字段按 `YYYYMMDD` 传递。
> - 统一响应结构 **`{ code, message, data }`**，`code = 0` 为成功；非 0 的 code 与 message 供前端提示定位。
> - 分页统一 `data: { records, total, page, size }`。
> - 鉴权：除公开接口外，请求头携带 `Authorization: Bearer {token}`。
> - 状态码：`401` 未登录/令牌失效；`403` 已登录但角色或归属不足；`404` 资源不存在；`500` 服务异常。
> - AI 生成、智能问答采用 **SSE 流式**返回。
>
> **前端现状**：`src/api/index.js` 为 Mock 实现（函数与下表端点一一对应），后端就绪后替换函数体为 `src/api/request.js` 的 `get/post/put/del` 即可，页面零改动。

## 七、通用约定小结

- **统一返回**：`{ code, message, data }`；`code = 0` 成功、`401` 未登录、`403` 无权限、`404` 不存在、`500` 服务异常
- **分页**：`data` 为 `{ records, total, page, size }`
- **鉴权**：请求头 `Authorization: Bearer {token}`
- **流式**：`/ai/generate`、`/ai/ask/{caseId}` 采用 SSE；生成接口先推送过程事件再推送正文
