## 一、技术栈

| 项 | 选型 |
|---|---|
| 框架 | Vue 3.5（Composition API + `<script setup>`） |
| 构建 | Vite 8 |
| UI 组件库 | Element Plus 2.14（全量引入，中文 locale，图标全局注册） |
| 状态管理 | Pinia |
| 路由 | Vue Router 4（History 模式） |
| HTTP | axios（预留，接后端用） |
| 图表 | echarts（统计看板） |

## 四、Mock 与真实接口切换

当前 `src/api/index.js` 全部为 **Mock 实现**（不经过 axios），函数签名与《前端接口调用清单》一致，接口前缀 `/api/v1`、响应结构 `{ code, message, data }`（`code = 0` 成功）。接后端时：

1. 在后端完成 D6 接口契约对应接口后，将 `api/index.js` 各函数体替换为 `request.js` 的调用（`get/post/put/del`）
2. `request.js` 已内置 token 注入、401/403/500 统一处理（成功判定为 `code === 0`）
3. AI 生成/问答接口改为 fetch + ReadableStream 解析 SSE，页面零改动
4. 若后端代理需开启，在 `vite.config.js` 配置 `/api` proxy

- 端口 5174（已在 vite.config.js 固定，与原项目 5173 区分）
